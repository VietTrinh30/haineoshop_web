Current Variant Architecture

Understanding the current data model before proposing changes

Current Data Model — Global Collections
🗂️ variantTypes (GLOBAL)
Shared by ALL products
label: "Loại"
name: "loai"
options: → join variantOptions
label: "Size"
name: "size"
options: → join variantOptions
🏷️ variantOptions (GLOBAL)
Shared by ALL products
variantType: → Loại
label: "DAY - Có màu"
value: "day-co-mau"
variantType: → Loại
label: "NIGHT - Ko màu"
variantType: → Size
label: "M"
variantType: → Size
label: "L"
📦 Product A
enableVariants: true
variantTypes: → [Loại, Size]
variants: → join variants
📦 Product B
enableVariants: true
variantTypes: → [Loại, Size]
⚠️ Same types & options as Product A!
⚠️ Problem
If Product A has type "Loại" with options ["DAY", "NIGHT"],
Product B also sees the same "Loại" with ["DAY", "NIGHT"]
even if Product B needs completely different options like ["Hồng", "Trắng"]
