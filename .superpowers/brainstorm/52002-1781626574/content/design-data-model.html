Review the proposed schema changes — does this look right?

Product Document — New Fields
// Product collection — fields that CHANGE
{
// ... existing fields (title, price, categories, etc.) ...

enableVariants: checkbox // ← kept as-is

variantTypes: relationship → variantTypes (hasMany)
// ↑ REMOVED — replaced by inline array below

+ variantTypeDefs: array [
id: string (auto-generated by Payload)
label: text, required // e.g. "loại", "size"
options: array [
id: string (auto-generated by Payload)
label: text, required // e.g. "DAY - Có màu", "M"
]
]

variants: join → variants // ← kept as-is (join by product)
}
Gallery Field — Minor Change
gallery: array [
image: upload → media
variantOption: relationship → variantOptions
+ variantOptionId: text
// stores the inline option array item id
// shown as select dropdown populated from
// FIRST variant type's options
]
Variant Collection — Modified
variant {
title: text // auto: "DAY - Có màu / M"
product: → products
options: relationship → variantOptions (hasMany)
+ options: json
// [{typeId: "abc", optionId: "xyz"}, ...]
inventory: number
priceInVND: number
}
🗑️ Collections to Remove
variantTypes — replaced by product.variantTypeDefs array
variantOptions — replaced by nested options array inside variantTypeDefs
✅ Collections Kept
variants — modified options field, still separate docs for cart/order refs
products — new inline fields, gallery updated
